# Download Speed Test

Небольшой скрипт на Python с использованием `asyncio` и `aiohttp`.

Скрипт делает 10 последовательных запросов к изображению, дожидается полной загрузки каждого ответа, считает среднее время запроса, общий объём скачанных данных и скорость скачивания.

Также добавил возможность выполнять запросы параллельно, просто потому что захотелось.

## Запуск

Python 3.10+

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Запуск:

```bash
python main.py
```

В `main.py` уже указан URL изображения. При необходимости его можно поменять.

Параметры `get_image`:

- `url` — адрес изображения.
- `count` — количество запросов (по умолчанию 10).
- `headers` — HTTP-заголовки.
- `cookies` — cookies.
- `sync` — `True` для последовательных запросов, `False` для параллельных.

По умолчанию используется последовательный режим, как и требуется в задании.

Результат выводится в консоль:

- Среднее время запроса — в секундах.
- Общий объём скачанных данных — в МБ (1 МБ = 1024² байт).
- Скорость скачивания — в МБ/с.
